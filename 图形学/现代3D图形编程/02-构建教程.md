# 构建教程

本节描述如何构建这些教程。

**你需要下载什么**

显然，你需要一个 C++ 编译器和构建环境。你还需要 Windows 或 Linux 操作系统，因为教程只支持这两种操作系统。支持的构建环境包括 Visual Studio 2008/2010、Code::Blocks 以及基于 Linux 的 GNU Makefile。其他构建系统也许可用，但并未经常测试。

你还需要下载[源码发行包](https://github.com/paroj/gltut/releases)，请下载版本号最高的那个 .zip 文件。构建教程所需的全部库都随发行包一起提供，因此这是你唯一需要下载的源码。

你还需要为你的平台下载并安装 [CMake](https://cmake.org/) 工具。

为了构建这些教程，你还需要对命令行有最基本的熟悉程度。另外，本文中提到的所有目录都是相对于你解压这个发行包的位置而言。

**发行包的文件布局**

教程目录中文件的布局相当简单。`framework `目录以及所有形如 `Tut *` 的目录包含教程本身的源代码。每个 `Tut* `目录都有对应各个教程的代码。`framework ` 目录只包含每个教程都会用到的通用工具代码。

每个教程包含一个或多个项目；正文中会针对该教程引用这些项目。

`Documents ` 目录包含解释这些教程如何工作的文本文档源码。这些源码采用 DocBook 5.0 格式的 xml 文件。

其余目录要么包含教程所用的库，要么包含教程加载的数据文件。

**CMake**

CMake 为特定平台生成构建文件。CMake 的构建脚本使用自己的语言。

请注意，CMake 只负责生成构建文件；构建文件生成之后，你就可以像平时一样使用它们。它可以生成 Visual Studio、[Code::Blocks](http://www.codeblocks.org/) 的项目文件，以及 GNU Makefile。而且除非你想修改某个教程，否则你只需要运行一次 CMake。

下载的 CMake 为所有目标平台（包括 Linux）都提供了预编译的可执行文件。

**非官方 OpenGL SDK**

教程中附带了非官方 OpenGL SDK（你不需要单独下载）。它把若干个用于开发 OpenGL 应用的工具统一到一套构建系统下。无需下载；教程发行包中已包含一份 SDK。随这些教程提供的副本不包含文档和 GLFW。

SDK 的库同样使用 CMake 构建。教程的构建过程会识别 SDK，并在你按下文所述方式构建教程时顺便把它构建好。

构建 SDK 时不需要执行 `make install` 或类似命令。SDK 的设计就是就地使用；它不会把自己安装到机器上的任何系统目录。顺便一提，这些教程也一样。

**教程的构建与运行**

所有教程会一次性构建；请进入发行包的根目录，对该目录下的 `CMakeLists.txt ` 文件使用 CMake。它会把所有教程放进同一个项目，你可以一次性构建它们。

每个教程通常有不止一个源文件，并生成多个可执行程序。每个可执行程序对应教程的一个不同章节，具体在该教程的文档中有说明。

如果你查看任何一个教程的源文件，都不会找到 `main `函数的定义。这个函数定义在 `framework/framework.cpp ` 中；它以及 `framework ` 目录中的所有其他源文件都由每个教程共享。它负责一些样板性的基础工作：创建 FreeGLUT 窗口等。这样教程的源文件就可以专注于有用的 OpenGL 专属代码。

请注意，framework 项目是一个库，而不是可执行程序。因此，试图从你选择的 IDE 中运行 framework 是行不通的。你必须选择某个教程项目并把它设为当前项目，然后才能从 IDE 中运行该教程。

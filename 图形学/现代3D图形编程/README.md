# 现代 3D 图形编程（中文版）

> 《Learning Modern 3D Graphics Programming》中文版 —— 从向量数学到高级光照与纹理的 OpenGL 现代渲染管线教程。
> 原作者：Jason L. McKesson｜原书采用 CC BY 3.0 许可发布。

这是一本**从零开始、逐层递进**的现代 OpenGL 图形编程教材。它不只教你 API 怎么调用，而是先讲清**渲染原理、向量数学与硬件管线**，再一步步构建出可交互的 3D 场景、动态光照与高级纹理效果。

## 为什么读这本

- **讲原理，不讲速查表**：每个 API 背后都解释「为什么这样设计」，面试与深入学习都经得起追问。
- **可运行代码**：全书 212 个代码示例（C++ / GLSL），配套完整工程。
- **公式完备**：67 个公式已渲染为矢量图，透视投影、光照模型、Gamma、纹理采样推导一应俱全。
- **169 张示意图**：光栅化流程、坐标系变换、法线变换、mipmap、立方体贴图等全部配图。

## 学习要点

| 模块 | 核心内容 |
| --- | --- |
| 渲染基础 | 向量/矩阵数学、归一化设备坐标、扫描转换、光栅化器、着色器、VAO/VBO/IBO |
| 空间定位 | 3D 变换、透视投影、视锥与宽高比、深度缓冲与深度裁剪、绕序与背面剔除、层级变换、相机空间、四元数与插值 |
| 光照 | 漫反射、法线变换（逆转置）、环境光、点光源与衰减、Phong / Blinn-Phong 高光、HDR 与 Gamma 校正、替身渲染 |
| 纹理 | 纹理坐标与透视校正插值、放大/缩小过滤、mipmap、各向异性过滤、sRGB、投影纹理、立方体贴图 |
| 工程实践 | 顶点格式与步长、瓶颈定位、CPU/GPU 同步、Voodoo 到统一架构的显卡史 |

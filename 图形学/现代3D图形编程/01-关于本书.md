# 关于本书

三维图形硬件正在迅速成为计算机系统中不可或缺的组件，而不仅仅是可有可无的配件。许多操作系统直接使用、甚至必须依赖某种程度的三维渲染硬件。即使在日益重要的移动计算领域，三维图形硬件也是除最低端设备之外所有设备的标准配置。

如何充分发挥这些硬件的能力，是一项困难的挑战，尤其是对于刚接触图形学与渲染的人而言。

## 为什么读这本书？

市面上有大量讲授图形学的纸质书籍，也有数量更多的在线知识库，形式包括 wiki、博客、教程和论坛。那么这本书能提供什么别人没有的东西？

可编程性。上述来源几乎都用所谓的“固定功能”来教导初学者。它指的是老式图形处理器中的一系列配置，用来定义某项渲染操作将如何进行。普遍认为，用固定功能管线来教初入门的图形程序员是最容易的。

之所以这么认为，是因为用固定功能很容易让某个效果“跑起来”。做出看起来像真实物体的图像也更容易。固定功能管线就像自行车的辅助轮。

这种做法也有它的缺点。首先，用这种方式学到的许多东西，一旦用户遇到必须用可编程性才能解决的图形问题，就不得不被彻底抛弃。可编程性几乎抹掉了固定功能管线的全部内容，因此这些知识很难迁移过去。

还有一个更隐蔽的问题：固定功能管线会给人知识的*假象*。用户以为自己明白了在做什么，实际上只是在到处复制粘贴代码。于是编程就变得近乎某种魔法仪式：把某些代码片段放在另一些代码片段前面，一切似乎就都正常工作了。

这会让调试变成噩梦。因为用户从来没有真正理解代码的作用，所以无法诊断某个具体问题可能意味着什么。而缺少这种能力，调试就变成了一连串关于问题究竟是什么的随机猜测。

与此相对，不先理解可编程系统，你就无法成功地使用它。要面对可编程图形硬件，就意味着要去面对固定功能教材常常一笔带过的问题。这可能意味着整体上起步更慢，但当你终于走到终点时，你是真的*知道*一切是如何工作的。

另一个问题是，即便你确实理解了固定功能管线，它也会限制你思考问题的方式。由于它缺乏灵活性，它会把你的思路引导到某些解题可能性上，而远离另一些。它鼓励你把纹理看成图片，把顶点数据看成纹理坐标、颜色或位置之类的东西。就其本质而言，它限制了创造力和解决问题的能力。

最后，即便在移动系统上，图形硬件通常也不提供固定功能。可编程性是当今大多数图形硬件的主流，而未来只会更加如此。

本书提供的是初学者层面的指导，而主题是很多人认为高深的内容。它从零开始，向初入门的图形程序员讲解可编程渲染。

本书还覆盖了一些重要但常被忽略、或被归入“高级”概念的材料。这些概念其实并不高级，只是由于它们无法与固定功能管线配合，多数入门材料往往避而不谈。

本书首先、最重要的是关于如何成为图形程序员。因此，只要有可能并且实用，本书就会以一种鼓励读者以全新且有趣的方式去探索图形硬件能力的方式来呈现材料。优秀的图形程序员把图形硬件看作满足自身需求的一套工具，本书正试图鼓励这种思维方式。

不过，本书有一件事不是：它不是一本图形 API 的书。虽然它使用 OpenGL，并且出于必要性用 OpenGL 的术语讲授渲染概念，但它并不是 OpenGL API 的全面指南。本书会按各种图形概念的需要覆盖 API 的大部分内容，但 API 支持的许多功能不会被涉及。如果你已经了解图形学，需要的是一本讲授现代 OpenGL 编程的书，那么本书对你来说可能太基础了。本书会教你 API 中最大的一部分，但本书的重点更多在图形学本身，而非 API 本身。

本书的目标是教会你如何成为一名图形程序员。它不针对某个特定的图形细分领域，而是要覆盖三维渲染的大部分基础知识。所以无论你想做游戏开发、CAD 程序设计、计算机可视化，还是其他任何方向，本书对你依然有价值。这并不意味着它涵盖了三维图形的一切内容，远没有。它试图为你继续探索自己感兴趣的任何一个三维图形方向打下坚实的基础。

本书没有深入覆盖的一个主题是优化。原因很简单：真正的优化是一个高级话题。优化往往与平台相关，针对不同类型的硬件做法不同；也可能与 API 相关，因为不同 API 的优化需求各不相同。书中会零星提到优化，但对这个主题来说，对初入门的图形程序员而言它实在太过复杂。附录中有一章讨论优化的机会，但那只提供了较高层次的概览。

## 你需要准备什么

这是一本写给图形编程初学的书；对于那些熟悉基于固定功能的图形学、想更好地理解可编程渲染的人来说，它也可以是一本不错的入门教材。

本书不是写给初学*程序员*的。

你应当能够阅读 C 和还算靠谱的 C++ 代码。如果你对 C/C++ 的了解只到“你好，世界！”这个程度，那么也许你应该先写一些更有实质内容的代码，再来尝试渲染图像。三维图形渲染根本不是初级的编程任务；这一点对传统图形学学习与现代图形学学习同样成立。

这些教程也应当能迁移到其他语言。如果你能读懂 C/C++，就足以理解代码在做什么。解释代码作用 的文字说明也足以让你从这些教程中获取信息。

任何对三维渲染的实质性讨论都需要先讨论数学，因为数学是全部三维图形学的基础。本书假定你了解基础几何与代数。本书会在需要时介绍图形学所需的更高级数学，但你至少应当对几何与代数有可用的知识。线性代数不是必需的。

本书的源代码使用 OpenGL 作为渲染 API。你在开始时不需要了解 OpenGL，但为了编译和运行这里的任何代码，你必须具备一个支持 OpenGL 的开发环境。

具体来说，你需要能够运行 OpenGL 3.3 版的图形硬件。这意味着任意 GeForce 8xxx 或更新的显卡，或者任意 Radeon HD 级别的显卡。它们也被称为“Direct3D 10”显卡，但要在 OpenGL 中使用它们的高级特性并不需要 Windows Vista 或 7。你应当安装最新的显卡驱动，可以从显卡厂商的主页获取。除了驱动和教程发行包本身，你不需要下载或安装任何其他东西就能使用 OpenGL。

### 保持开放

本书面向图形程序员，讲解图形开发的基础。你自己能带来的最重要的东西，是学习的意愿。这也意味着要放下成见，而且最重要的是，不要试图去学某个特定的东西。

程序员常常会翻遍互联网或埋头啃书，寻找如何完成某项特定任务的信息。一旦找到，他们就会试着把那段代码复制进自己的应用，看看能不能跑通。这个方法可以更快出结果，但它损害学习，因为注意力被放在达成某个效果目标上，而不是真正理解它是如何工作的。

初次接触本书时，你应当尽量避免带着具体问题去思考。你可以心里记着某个问题，但不要让对解决方案的寻找驱动你的阅读。专注于所呈现的材料。等你读完本书，再回头看看是否理解了该怎么解决那个你想解决的问题。

你可能会发现，你有了比原本会想到的更好的解决方案。

## 本书的组织方式

本书被拆分为若干个大的主题。每个主题包含若干编号章节，称为教程。每个教程讲述若干相关的概念。几乎在所有情况下，每个概念都配有一组对应的代码来演示。

每个教程都以将要讨论和演示的概念的概览开篇。每个教程的末尾是一节复习内容，以及该教程中引入的所有术语的术语表。复习部分会讲解教程中呈现的概念，其中还会给出一些动手改动源代码的建议，目的是加深你对这些概念的理解。如果该教程引入了新的 OpenGL 函数或 OpenGL 着色语言函数，也会在此一并回顾。

这是一本给图形编程初学者看的书。图形学是一个庞大的主题，任何一本书都不可能覆盖所有可能的效果、特性或技巧。本书同样不会详尽无遗地覆盖每一种技巧。有些技巧会在后面的材料中重新出现，但要把所有东西讲完，篇幅实在不够。因此，在介绍某些技巧时，章节末尾会提供一个章节，对更高级的技巧做些粗略的考察。这会帮助你进一步研究图形编程，因为你会知道该在网上或在其他书里搜索什么。

每个教程都以该教程中定义的所有术语的术语表结束。

**注意：浏览器说明**

> 本网站和这些教程大量使用 SVG 图像。除 IE 9 之前的所有 Internet Explorer 版本外，所有主流浏览器都具备基本的 SVG 支持。如果你满足于这些版本的 Internet Explorer（或无法升级），可以考虑为 IE8 安装 Google Chrome Frame 插件，这样就能正确显示图像。

## 本书使用的约定

本书的文字按照约定的样式来排版。文字样式表示被标记的文字代表什么。

- 定义术语：该术语会在每个教程末尾的术语表中给出定义。
- `FunctionNames `：可能是 C、C++ 或 OpenGL 着色语言中的名称。
- `nameOfVariable `：可能是 C、C++ 或 OpenGL 着色语言中的名称。
- `GL_ENUMERATORS `-`Names/Of/Paths/And/Files `
- <kbd>K</kbd>：键盘上的按键“K”，它与字母大写“K”不同。按下 <kbd>Shift</kbd> 加 <kbd>K</kbd> 得到的才是字母大写 K。

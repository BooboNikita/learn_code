# 系统架构设计师 · 考纲与考点全景

> 对照 2022 年审定通过的官方《系统架构设计师考试大纲》与《系统架构设计师教程（第 2 版）》，给出**完整考点地图**，并标注本站当前的覆盖情况。
>
> **结论先行**：[系统架构设计](系统架构设计.md) 那份讲义只覆盖了官方考纲的**一小块**（科目一第 6、7 章），远不是全部。完整考纲共 3 个科目、28 个板块。

## 一、考试科目设置

| 科目 | 官方名称 | 题型 | 时长 | 满分 |
| ---- | -------- | ---- | ---- | ---- |
| 科目一 | 系统架构设计综合知识 | 单选 75 题 | 150 分钟（与科目二连考，共 240 分钟） | 75 分 |
| 科目二 | 系统架构设计案例分析 | 问答（5 题，第 1 题必答） | 90 分钟 | 75 分 |
| 科目三 | 系统架构设计论文 | 4 选 1 论述 | 120 分钟 | 75 分 |

- 各科目**均为 45 分及格**，且必须**一次通过全部科目**方可拿证（单科成绩不保留）。
- 案例试卷一般给 5 道题：**试题一必答**，其余 4 题选 2 道作答。

## 三、科目二「案例分析」完整考纲（9 大板块）

| # | 板块 | 主要考点 |
| - | ---- | -------- |
| 1 | **系统计划** | 系统项目的提出与可行性分析、系统方案的制定/评价和改进、新旧系统的分析和比较、现有软硬件和数据资源的有效利用 |
| 2 | **信息系统架构**的设计理论与实践 | 概述、信息系统架构设计方法 **ADM**、信息化总体架构方法 |
| 3 | **层次式架构**的设计理论与实践 | 概述、表现层框架设计、中间层架构设计、数据访问层设计、数据层架构规划与设计、**物联网的层次架构设计**、案例分析 |
| 4 | **云原生架构**设计理论与实践 | 概述、相关技术（容器/微服务/DevOps/服务网格等）、案例分析 |
| 5 | **面向服务的架构（SOA）**设计理论与实践 | 概述、设计、实施过程 |
| 6 | **嵌入式系统**的架构设计理论与实践 | 概述、软件架构的原理与特征、设计方法、案例分析 |
| 7 | **通信系统架构**的设计理论与实践 | 通信系统的架构、网络构建的关键技术、网络构建和设计方法、网络安全相关技术、案例分析 |
| 8 | **安全架构**的设计理论与实践 | 概述、系统安全体系架构规划框架、信息安全整体架构设计（**WPDRRC 模型**）、网络安全体系架构设计、数据库系统的安全设计、**系统架构的脆弱性分析**、案例分析 |
| 9 | **大数据架构**设计理论与实践 | 大数据处理系统概述、典型的大数据架构（Lambda / Kappa）、案例分析 |

> **「八大架构」就在这里**——第 2～9 板块共 8 种架构，即**信息系统架构、层次式架构、云原生架构、面向服务架构、嵌入式系统架构、通信系统架构、安全架构、大数据架构**。讲义里说的"偶尔考八大架构"指的正是这一组。
>
> 案例题的分布规律：**试题一固定落在科目一的第 6、7 章**（架构风格 + 质量属性），第 2～5 题通常从"八大架构"里挑 2～3 个出题，且近年越来越偏向"新技术 + 架构"结合的超纲题。
>
> ✅ **本站已覆盖**：第 2～9 板块已汇总为 [八大架构](八大架构.md)（速览版，只留高频必背考点）。

## 四、科目三「论文」完整考纲（6 大板块）

> 官方大纲原文编号有跳号（1、3、4、5、6、7），实际为 6 个板块。

| # | 板块 | 主要考点 |
| - | ---- | -------- |
| 1 | **系统建模** | 定义问题与归结模型、结构化系统建模、面向对象系统建模、数据库建模、可靠性建模、系统评估建模 |
| 2 | **软件架构设计** | **软件架构风格选择**、软件架构设计、特定领域软件架构 |
| 3 | **基于架构的软件开发方法** | 属性驱动的软件设计方法、实时系统设计方法、**软件架构演化**、架构质量和评估、**架构脆弱性分析** |
| 4 | **系统设计** | 信息系统总体框架设计、大数据处理系统流程设计、SOA 及分布式系统总体设计、系统人机界面设计、嵌入式系统设计、数据库系统设计、文件与存储设计、通信和网络应用系统设计、系统运行环境集成与设计、系统性能设计、系统安全性和可靠性设计、中间件与构件化系统设计 |
| 5 | **系统的可靠性分析与设计** | 故障模型和可靠性模型、提高系统可靠性的措施、故障对策与系统备份恢复、可靠性分析/预计与评估 |
| 6 | **系统的安全性和保密性设计** | 访问控制技术、数据的完整性、数据与文件的加密、通信的安全性、系统的安全性设计 |

**论文的备考套路**：准备 2～3 个可复用的真实项目素材（背景 + 技术选型 + 遇到的问题 + 量化结果），考场上按"**摘要 → 项目背景 → 理论论述（对应考纲板块）→ 本项目怎么做 → 效果与不足**"填空即可。本站已覆盖的第 2、3 板块是最常出的论文题。

> ✅ **已整理为 [论文写作](论文写作.md)**：考试规则与阅卷标准、**万能十段式模板**、摘要/背景/结尾固定件、**六大题型 → 分论点拆解表**、素材弹药库、120 分钟时间分配、5 个预测题分论点清单。科目三 6 大板块中的**系统建模**、**可靠性设计**、**安全性设计**三块的具体论述素材尚未展开。

## 五、官方教程（第 2 版）整体结构

《系统架构设计师教程（第 2 版）》（叶宏主编，清华大学出版社，ISBN 9787302619925），全书分**上下两篇、共约 20 章**：

- **上篇 · 综合知识**：绪论、计算机系统、信息系统、信息安全技术、软件工程、**数据库设计**、**系统架构设计**、**系统质量属性与架构评估**、软件可靠性、软件架构的演化和维护、未来信息综合技术等。
- **下篇 · 案例分析**：信息系统架构、层次式架构、云原生架构、面向服务架构、嵌入式系统架构、通信系统架构、安全架构、大数据架构。

> 也就是说，本站现有的讲义覆盖的是**上篇的计算机系统（硬件/操作系统/嵌入式）、计算机网络、信息安全技术、软件工程、数据库设计、系统架构设计、质量属性与架构评估七块**，以及下篇 8 章（案例分析主力）——上篇其余章节、下篇的深挖案例仍是空白。

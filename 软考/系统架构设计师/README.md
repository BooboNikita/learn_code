# 系统架构设计师

> 软考**高级**资格，上下半年均开考。三科连考：**综合知识（单选 75 题）+ 案例分析（问答）** 合计 240 分钟，**论文** 120 分钟；须一次通过全部科目。核心能力是"**把业务与质量需求翻译成架构决策，并能用视图/场景说清楚**"。

## 学习要点

- **架构风格**：五大类 13 种风格的构件/连接件模型、适用场景与脆弱性；能识别题目描述对应哪种风格（案例与选择题高频）。
- **架构复用**：机会复用 vs 系统复用，可复用资产清单，复用三阶段。
- **DSSA（特定领域软件架构）**：垂直域/水平域、三个基本活动、四类角色、建立过程五阶段。
- **ABSD（基于架构的软件设计）**：业务/质量/功能组合驱动，三个基础，自顶向下递归细化。
- **基于架构的软件开发流程**：架构需求 → 设计 → 文档化 → 复审 → 实现 → 演化。
- **质量属性**：开发期 6 项 + 运行期 7 项，以及 8 个核心质量属性的设计策略；**质量属性场景六要素**（刺激源/刺激/环境/制品/响应/响应度量）。
- **架构评估**：SAAM 与 ATAM 的定位、输入、活动步骤；效用树与场景类型。
- **易混辨析**：可用性 / 可靠性 / 鲁棒性（容错性），可修改性 / 可维护性 / 可扩展性 / 可移植性，功能性 / 互操作性。
- **软件工程（选择题量最大）**：软件过程模型与 RUP、逆向工程四级别、需求工程（获取六法 / DFD / CCB / 双向跟踪）、UML 关系与 14 种图、**结构化设计的耦合与内聚七级**、面向对象设计原则与设计模式、软件测试方法与六个阶段。
- **计算机系统基础与操作系统（选择题稳定得分）**：冯·诺依曼五部件、**存储器四层**（片上缓存/片外缓存/主存/外存）、CISC vs RISC、总线分类；操作系统三大作用、**四大特征（并共虚不）**、七种分类；**进程三态转换条件**、**PV 操作**、**死锁四必要条件**与资源公式 **n(R−1)+1**、线程 vs 进程；页式存储地址变换、**页面置换 OPT/FIFO/LRU**、快表；文件物理结构三种、**位示图**计算；嵌入式 8 条特性、5 层结构、**DO-178C 五个安全等级**（Catastrophic → Level A）。
- **数据库（选择题稳定得分 + 案例超纲热点）**：**三级模式两级映像**、数据库设计六阶段与产出物、E-R 模型（强/弱实体、三类冲突、E-R→关系三条转换规则）、函数依赖与码、**范式 1NF～4NF**、关系代数五种基本运算与符号（选择 σ 取行 / 投影 π 取列）、SQL 关键字、事务 **ACID** 与并发三问题、**共享锁/排他锁**；案例必看**乐观锁/悲观锁对比 + Redis 三种防超卖方案**。
- **网络与信息安全（选择题得分稳）**：奈奎斯特/香农公式与子网掩码计算、曼彻斯特编码、局域网 5 种拓扑、**OSI 七层分层与设备归属**、TCP/IP 协议族；信息安全 5 个基本要素、对称 vs 非对称加密及算法归类、信息摘要（MD5/SHA-1）、数字签名与数字信封、**PKI 三类实体**、防火墙/VPN/IPSec/Kerberos、访问控制三要素与 ISO 7498-2 五类安全服务。
- **八大架构（案例主线）**：TOGAF/ADM、层次式（表现层/中间层/数据访问层 + 物联网三层）、云原生七大原则与主要架构模式、SOA 与微服务对比、嵌入式实时调度算法（EDF/LLF/RMS）与嵌入式数据库三类、局域网/广域网拓扑、安全模型（BLP/Biba/Clark-Wilson/Chinese Wall）与 WPDRRC、架构脆弱性分析、Lambda/Kappa 大数据架构。

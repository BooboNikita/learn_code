# 🎓 软考

> 计算机技术与软件专业技术资格（水平）考试，简称**软考**，由工信部教育与考试中心主办，是 IT 领域唯一以考代评的国家级职业资格考试。通过高级资格即具备**高级工程师**职称评定资格（以考代评），也是很多城市落户积分的加分项。

## 一、考试体系

| 级别 | 代表资格 | 考试科目 |
| ---- | -------- | -------- |
| 高级 | 系统分析师、**系统架构设计师**、信息系统项目管理师、网络规划设计师、系统规划与管理师 | 综合知识、案例分析、论文 |
| 中级 | 软件设计师、网络工程师、数据库系统工程师、系统集成项目管理工程师…… | 基础知识、应用技术 |
| 初级 | 程序员、网络管理员、信息处理技术员 | 基础知识、应用技术 |

**关键规则**

- 各科目均为**计算机化考试（机考）**，科目**连考**，且必须**一次通过全部科目**才发证（单科成绩不保留）。
- 报考**不受学历、资历、年龄限制**，按属地原则选择考区。
- 报名入口：[中国计算机技术职业资格网](https://www.ruankao.org.cn)（须先用"国家网络身份认证"APP 完成实名认证）。
- 成绩于考试结束之日起 45 日内开放查询。

## 二、2026 年考试安排

| 项目 | 上半年 | 下半年 |
| ---- | ------ | ------ |
| 考试日期 | 5 月 23 日至 26 日 | 10 月 24 日至 27 日 |
| 报名（信息填报） | 3 月 23 日 9:00 起 | 8 月 17 日 9:00 起 |
| 打印准考证 | 5 月 19 日至 22 日 | 10 月 20 日至 23 日 |

- **高级**：综合知识与案例分析连考，作答总时长 **240 分钟**（综合知识最长 150 / 最短 120 分钟，节余时间可给案例）；论文 **120 分钟**，不得提前交卷。
- 上半年与下半年均开考**系统架构设计师**。

> 各地报名起止时间略有差异，以所在考区通知为准。

## 三、学习要点

- **高级（系统架构设计师）**：架构风格与架构评估、质量属性与质量属性场景、DSSA 与 ABSD、基于架构的软件开发流程、系统建模（Petri 网、UML）、领域驱动设计、大数据架构、云原生与微服务、信息安全与加密。
- **备考主线**：案例试题一（质量属性 + 架构风格）是**拿分基本盘**，论文需要提前准备 2–3 个可复用的项目素材并背熟"质量属性 + 架构风格"的论述套路。
- **答题技巧**：机考可用微软拼音/搜狗拼音/搜狗五笔；案例题**问什么答什么、按分值给条目**，每问写满对应条数。

# C++

> 高性能系统级语言，兼顾底层控制与抽象能力，广泛用于后端服务、游戏引擎、嵌入式、音视频、数据库等领域。

## 学习要点

- 基础：指针与引用、const/static、内存分区、RAII。
- 面向对象：封装继承多态、虚函数与虚表、构造/析构/拷贝语义。
- 现代 C++（C++11 起）：auto、lambda、智能指针、右值引用与移动语义。
- 标准库：STL 容器与迭代器失效、算法、`std::function`。
- 并发：线程、互斥锁、条件变量、原子操作、线程安全单例。
- 构建：CMake 工程组织、目标与依赖管理、安装导出。
- 面试与实战：手写 string/shared_ptr、内存泄漏排查、性能优化。

## 版本演进

C++ 标准约三年一迭代，从 C++98 到 C++23 共七个版本。其中 **C++11、C++17、C++20** 是三个里程碑，**C++98/03、C++14、C++23** 属于奠基或小步迭代。

## 学习要点

- **图形学基础**：向量/矩阵数学、坐标空间、光栅化、深度缓冲。
- **渲染管线**：顶点/片元/几何着色器、VBO/VAO/UBO、FBO。
- **光照**：漫反射、高光模型、法线变换、HDR 与 Gamma。
- **纹理**：采样器状态、mipmap、各向异性过滤、投影纹理、立方体贴图。
- **工程优化**：顶点格式、批次、瓶颈分析、CPU/GPU 同步。

# 系统架构设计师

> 软考**高级**资格，上下半年均开考。三科连考：**综合知识（单选 75 题）+ 案例分析（问答）** 合计 240 分钟，**论文** 120 分钟；须一次通过全部科目。核心能力是"**把业务与质量需求翻译成架构决策，并能用视图/场景说清楚**"。

## 学习要点

- **架构风格**：五大类 13 种风格的构件/连接件模型、适用场景与脆弱性；能识别题目描述对应哪种风格（案例与选择题高频）。
- **架构复用**：机会复用 vs 系统复用，可复用资产清单，复用三阶段。
- **DSSA（特定领域软件架构）**：垂直域/水平域、三个基本活动、四类角色、建立过程五阶段。
- **ABSD（基于架构的软件设计）**：业务/质量/功能组合驱动，三个基础，自顶向下递归细化。
- **基于架构的软件开发流程**：架构需求 → 设计 → 文档化 → 复审 → 实现 → 演化。
- **质量属性**：开发期 6 项 + 运行期 7 项，以及 8 个核心质量属性的设计策略；**质量属性场景六要素**（刺激源/刺激/环境/制品/响应/响应度量）。
- **架构评估**：SAAM 与 ATAM 的定位、输入、活动步骤；效用树与场景类型。
- **易混辨析**：可用性 / 可靠性 / 鲁棒性（容错性），可修改性 / 可维护性 / 可扩展性 / 可移植性，功能性 / 互操作性。
- **八大架构（案例主线）**：TOGAF/ADM、层次式（表现层/中间层/数据访问层 + 物联网三层）、云原生七大原则与主要架构模式、SOA 与微服务对比、嵌入式实时调度算法（EDF/LLF/RMS）与嵌入式数据库三类、局域网/广域网拓扑、安全模型（BLP/Biba/Clark-Wilson/Chinese Wall）与 WPDRRC、架构脆弱性分析、Lambda/Kappa 大数据架构。

## 一、计算机网络

### 1.1 性能指标

| 指标 | 含义 |
| ---- | ---- |
| **速率**（数据率、比特率） | 主机在数字信道上传输数据的速率，单位 bit/s（比特每秒） |
| **带宽** | 两种含义：① 一个信号的**频带宽度**，单位 Hz；② 网络中单位时间内从一端到另一端能通过的**最高数据率**，单位 bit/s |
| **吞吐量** | 表示在单位时间内通过某个网络（或信道、接口）的数据量 |
| **时延** | 数据（一个报文、分组甚至比特）从网络一端传送到另一端所需的时间，有时也称为延迟 |
| **往返时间 RTT** | 从发送方发送数据开始，到发送方收到来自接收方的确认（接收方收到数据后便立即发送确认）总共经历的时间 |
| **利用率** | 信道利用率 = 有数据通过的时间占比；网络利用率 = 全信道利用率的加权平均值。**完全空闲时信道利用率为零** |

> ⚠️ 网络**非性能指标**：费用、质量、标准化、可靠性、可扩展性、可升级性、易管理性、可维护性。（"哪些**不属于**性能指标"本身就是考题）

### 1.2 速率极限：奈奎斯特 vs 香农 ⭑

| 定理 | 公式 | 约束条件 |
| ---- | ---- | -------- |
| **奈奎斯特**（极限速率） | `B = 2W`（Baud）；一个码元携带 `n = log₂N` 位信息（N 为码元种类数） | **带宽受限**（无噪声） |
| **香农**（有噪声极限速率） | `C = W·log₂(1 + S/N)` | **噪声受限** |

- **数据速率 ≠ 波特率**，仅当码元取两个离散值时两者数值才相等。
- S/N 在实际中比值太大，常取分贝：`dB = 10·log₁₀(S/N)`（如 30dB → S/N = 1000）。
- **实际最大速率 = min(奈奎斯特速率, 香农容量)**——两个约束谁的更紧就取谁。
- **提高传输速率（信道容量）的两条路**：用**较大的带宽** + 降低信噪比要求；或用**较小的带宽** + 升高信噪比。

**典型习题** ⭑（讲义原题）
某数字信道带宽 3000Hz，信噪比 30dB，用 8 种码元传输：
1. 奈奎斯特：`2 × 3000 × log₂8 = 6000 × 3 = 18000 bps`
2. 香农：`S/N = 1000`，`C = 3000 × log₂(1001) ≈ 3000 × 10 = 30000 bps`
3. 实际速率：`min(18000, 30000) = 18000 bps`

### 1.3 编码、调制与复用

- **发送方的信号处理**：信源编码（模拟信号→数字信号）、**信道编码**（增加冗余信息便于检错纠错）、**交织**（按规律打乱顺序，使连续错码变成零星误码）、脉冲成形、**调制**（把信息承载到高频载波上）。
- **接收方**：解调 → 采样判决 → 去交织 → 信道译码 → 信源译码。
- **复用 vs 多址**（易混）：
  - **复用**：在**一条信道上同时传输多路数据**的技术（TDM 时分复用、FDM 频分复用、CDM 码分复用）。
  - **多址**：在一条线上**同时传输多个用户**的数据，接收端把多个用户的数据分离（TDMA / FDMA / CDMA）。
- **曼彻斯特编码** ⭑：以太网物理层使用的编码，**自带同步时钟信号**（每比特中间有一次电平翻转），因此问"自带同步时钟的典型编码"就答它。
- **5G 特征**（8 条，略记关键词）：基于 OFDM 优化的波形与多址接入、可扩展的 OFDM 间隔参数配置、OFDM 加窗提高多路传输效率、灵活框架设计、大规模 MIMO（最多 256 根天线）、毫米波（频率大于 24GHz 以上频段）、频谱共享、先进信道编码（LDPC、Polar 码）。

### 1.4 局域网拓扑（5 种）

| 拓扑 | 特点 |
| ---- | ---- |
| **总线型** | 利用率低、干扰大、**价格低** |
| **星型** ⭑ | 交换机形成的局域网，**中央单元负荷大** |
| **环型** | 流动方向固定、效率低、**扩充难** |
| **树型** | 总线型的扩充，分级结构 |
| **分布式** | 任意节点连接、**管理难、成本高** |

### 1.5 OSI 七层模型 ⭑

| 层 | 功能关键字 | 单位 | 典型协议 | 典型设备 |
| - | ---------- | ---- | -------- | -------- |
| **1 物理层** | 在链路上**透明地传输比特**：线路配置、确定数据传输模式与信号形式、连接传输介质；规定机械/电气/功能/规程特性 | 比特 | EIA/TIA RS-232、RS-449、V.35、RJ-45、FDDI | 中继器、集线器 ⭑ |
| **2 数据链路层** | 把**不可靠的信道变为可靠的信道**：比特组成帧、**差错控制、流量控制** | 帧 | SDLC、HDLC、LAPB、PPP、STP、帧中继、IEEE802、ATM | 交换机、网桥 ⭑ |
| **3 网络层** | 在源节点—目的节点之间**路由选择、拥塞控制、顺序控制、传送包**；控制通信子网运行，故又称**通信子网层** | IP 分组 | IP、ICMP、IGMP、ARP、RARP | 路由器 ⭑ |
| **4 传输层** | 提供**端—端可靠、透明**的数据传输，保证报文顺序的正确性和数据的完整性 | 报文段 | TCP、UDP | 网关 |
| **5 会话层** | 建立通信进程的**逻辑名字与物理名字**之间的联系，提供进程间**建立、管理和终止会话**的方法，处理同步与恢复问题 | — | RPC、SQL、NFS | 网关 |
| **6 表示层** | 实现**数据转换**（格式转换、压缩、加密等），提供标准的应用接口、公用通信服务、公共数据表示方法 | — | JPEG、ASCII、GIF、MPEG、DES | 网关 |
| **7 应用层** | 对用户**不透明**地提供各种服务，如 E-mail | 数据 | Telnet、FTP、HTTP、SMTP、POP3、DNS、DHCP | 网关 |

> ⚠️ **三处最容易考混的**：
> ① 路由器属**网络层**，二层交换机属**数据链路层**；**路由转发不是数据链路层的功能**（真题原话）。
> ② OSI 七层中**只有会话层不提供安全服务**，其余各层均可提供（2024-05 真题）。
> ③ 最适合配置安全服务的是**物理层、网络层、运输层、应用层**，其他层都不宜配置。

### 1.6 TCP/IP 协议族 ⭑

- **网络协议三要素**：**语法、语义、时序**。语法规定传输数据的**格式**；语义规定所要完成的**功能**；时序规定各种操作的**条件与顺序关系**。

| TCP/IP 层次 | 对应 OSI 层 | 主要协议 |
| ----------- | ----------- | -------- |
| **应用层** | 应用层 + 表示层 + 会话层 | **POP3**、**FTP**、**HTTP**、**Telnet**、**SMTP**、Samba、CIFS、NFS、**DHCP**、**TFTP**、**SNMP**、**DNS** |
| **传输层** | 传输层 | **TCP**、**UDP** |
| **Internet 层** | 网络层 | **IP**、**ICMP**、**IGMP**、**ARP**、**RARP** |
| **网络接口层** | 数据链路层 + 物理层 | 以太网、令牌环、帧中继、ATM |

## 二、信息安全技术

### 2.1 信息安全 5 个基本要素 ⭑

**机密性、完整性、可用性、可控性、可审查性**（前三者即 CIA 三要素）。

| 要素 | 含义 |
| ---- | ---- |
| **机密性** | 确保信息**不暴露给未授权的实体或进程** |
| **完整性** | **只有得到允许的人才能修改数据**，并且能够判别出数据是否已被篡改 |
| **可用性** | 得到授权的实体**在需要时可访问数据**；**攻击者不能占用所有的资源而阻碍授权者的工作** |
| **可控性** | 可以控制授权范围内的**信息流向及行为方式** |
| **可审查性** | 对出现的信息安全问题**提供调查的依据和手段** |

**信息安全范围（4 个层面）**：**设备安全、数据安全、内容安全、行为安全**。

| 层面 | 含哪 3 个方面 |
| ---- | ------------- |
| **设备安全** | 设备的**稳定性、可靠性、可用性**。设备安全是信息系统安全的**首要问题**，是信息系统安全的**物质基础** |
| **数据安全** | 数据的**秘密性、完整性、可用性**（确保数据免受未授权的泄露、篡改和毁坏） |
| **内容安全** | 信息内容**在政治上健康**、**符合国家法律法规**、**符合道德规范**（政治、法律、道德层次的要求） |
| **行为安全** | 行为的**秘密性、完整性、可控性**（服务功能最终通过行为提供给用户，行为安全才能最终确保系统信息安全） |

> 安全需求四层：**物理安全、网络安全、系统安全、应用安全**。
> 安全技术：**加密技术、信息摘要、数字签名、数字证书、PKI**；网络安全技术：**防火墙、入侵检测、入侵防御**；安全协议：**SSL、SET、Kerberos、PGP**。

### 2.2 对称加密 vs 非对称加密 ⭑

| 维度 | 对称加密 | 非对称加密 |
| ---- | -------- | ---------- |
| 密钥 | 加解密密钥**相同**，属于**不公开密钥**加密算法 | 加解密密钥**不同**，分公钥和私钥，是**公开密钥**加密算法 |
| 缺点 | **加密强度不高**（密钥位数少）；**密钥分发困难**（密钥还要传给接收方，也要考虑保密性） | **加密速度慢** |
| 优点 | **加密速度快，适合加密大数据** | **安全性高、不容易破解；无需传输密钥** |
| 原理 | — | 用**接收者的公钥**作加密密钥、**私钥**作解密密钥 → 只有接收者能解出明文；**但无法保证完整性** |
| 常见算法 | **DES、3DES、AES、RC-5、IDEA** | **RSA**（512 或 1024 位密钥）、Elgamal、**ECC**（椭圆曲线）、背包算法、Rabin、D-H |

> ⚠️ **易错**：3DES 在**使用 2 个密钥**时，总密钥长度是 **112 位**（2 × 56）；用 3 个密钥才是 168 位。

### 2.3 信息摘要、数字签名、数字信封、PKI ⭑

- **信息摘要三特点**：① 不管数据多长，都产生**固定长度**的信息摘要；② 任何不同的输入数据都会产生**不同**的信息摘要；③ **单向性**——只能由数据生成摘要，不能由摘要还原数据。
- **摘要算法**：**MD5 产生 128 位**输出；**SHA-1**（安全散列算法）产生 **160 位**输出，安全性更高。
- **数字签名**：用于**唯一标识一个发送方**。发送者用**自己的私钥**加密，接收者只能用**发送者的公钥**解密 → 唯一确定发送方。**但无法保证机密性。**
- **数字签名流程**：明文 →（Hash 函数）→ 消息摘要 →（**A 的私钥 Sa** 签名）→ 签名摘要 → 互联网 →（**A 的公钥 Pa** 验证）→ 消息摘要 → 与收到的明文所算摘要**比较**。
- **数字信封**（同时保证机密性与完整性）：数据用**对称密钥**加密；**对称密钥本身用接收方的公钥加密**，这一小段就叫数字信封；接收方先用**私钥**解出对称密钥，再用它解数据。
- **PKI（公钥基础设施）**：以**非对称密钥加密技术**为基础，以**数据机密性、完整性、身份认证和行为不可抵赖性**为安全目的，来实施和提供安全服务的具有普适性的安全基础设施；包括**数字证书**和**签证机构 CA**。

> ⭑ **PKI 结构模型的三类实体**：**管理实体**（含 CA 与 RA，是 PKI 的**核心**、服务的提供者）、**端实体**（含证书持有者与验证者，是 PKI 的**用户**、服务的使用者）、**证书库**（一个**分布式数据库**，用于证书与 CRL 的存放和检索）。

### 2.4 网络安全设施与协议

| 概念 | 要点 |
| ---- | ---- |
| **防火墙** | 位于两个或多个网络之间、**执行访问控制策略**的一个或一组系统，是一类防范措施的总称；通常放在**外网和内网的中间**，执行网络边界的**过滤封锁机制** |
| **VPN** | 企业网在 Internet 等公共网络上的**延伸**，通过一个**私有的通道**在公共网络上创建一个安全的私有连接。本质上是一个**虚信道**，可连接两个专用网，用**可靠的加密技术**保证其安全性，**且是作为公共网络的一部分存在的** |
| **IPSec** | 工业标准**网络安全协议**，为 IP 网络通信提供**透明的安全服务**，保护 TCP/IP 通信免遭窃听和篡改。**两个基本目标**：保护 IP 数据包安全、为抵御网络攻击提供防护措施；靠**密码保护服务 + 安全协议组 + 动态密钥管理**三者实现 |
| **Kerberos** | 一种网络**身份认证协议**，基础是**基于信任第三方**；提供在开放型网络中进行身份认证的方法，**认证实体可以是用户也可以是用户服务** |
| **SSL / SET / PGP** | 常见安全协议。SSL：用**非对称加密协商会话密钥**，数据传输阶段用**对称加密**；**会话密钥是保密的，不是公开的** |

**访问控制三要素**：**主体、客体、控制策略**。

- **主体**：可以对其**他实体施加动作的主动实体**，有时也称为用户或访问者。
- **客体**：**接受其他实体访问的被动实体**；凡是可以被操作的信息、资源或对象都可以认为是客体。
- **控制策略**：主体对客体的**操作行为集合约束条件集**（访问规则集）。

> ⚠️ **访问控制矩阵（ACM）**：**行代表主体、列代表客体**，矩阵元素表示主体对客体的权限。

### 3.2 信息安全

| **2026-05** | **9.** 在操作系统的访问控制矩阵（ACM）模型中，矩阵的行和列分别代表（）<br>A 行代表客体，列代表主体　B 行代表主体，列代表客体　C 行代表权限，列代表客体　D 行代表主体，列代表权限 | **B**。行 = **主体**，列 = **客体** |
| **2026-05** | **28.** 下列关于 SSL（安全套接层）的描述中，错误的是（）<br>A SSL 使用公开密钥（非对称加密）来协商会话密钥　B SSL 可以用于客户端与服务器之间的加密通信　C SSL 的密钥是公开的，任何人都可以获取　D SSL 在数据传输阶段使用的是对称加密 | **C**。会话密钥是**保密**的，不可公开获取（A/B/D 均正确） |
| **2026-05** | **54.** 数字签名技术为保证完整性，主要综合应用了（）技术<br>A 对称加密与数字摘要　B 非对称加密与数字摘要　C 对称加密与非对称加密　D 数字摘要与哈希算法 | **B**。签名用**非对称加密**，完整性靠**数字摘要**（D 中"数字摘要"与"哈希算法"同义重复，是干扰项） |
| **2026-05** | **55.** DDoS（分布式拒绝服务攻击）主要破坏信息安全中的（）属性<br>A 机密性　B 可用性　C 完整性　D 认证机制 | **B**。耗尽资源导致无法正常服务 → **可用性**受损 |
| **2026-05** | **69.** 在信息安全领域，验证访问资源的实体与其所声明的身份是否一致，通常采用（）方式<br>A 审计　B 认证　C 访问控制　D 日志 | **B 认证** |
| **2025-11** | **23.** （）服务包括证据的生成、验证和记录，以及在解决纠纷时随即进行的证据恢复和再次验证<br>A 鉴权　B 抗抵赖　C 机密性　D 完整性 | **B 抗抵赖**（即不可否认性） |

| **2025-11** | **35.** 在公钥基础设施（PKI）体系中，通常将实体分为三类。正确表述这三类实体的是（）<br>A 管理实体、终端实体、对象实体　B 管理实体、终端实体、证书库　C 终端实体、对象实体、证书库　D 管理实体、对象实体、证书库 | **B**。**管理实体（CA/RA）、端实体（持有者/验证者）、证书库** |
| **2025-05** | **60.** OSI 开放系统互联安全体系的 5 类安全服务包括（）<br>A 鉴别 访问控制 机密性服务 完整性服务 不可抵赖性服务　B 认证 访问控制 机密性服务 完整性服务 不可抵赖性服务　C 认证 鉴别 机密性服务 完整性服务 不可抵赖性服务　D 认证 鉴别 访问控制 机密性服务 完整性服务 | **A**。ISO 7498-2 规定五类安全服务：**鉴别、访问控制、数据保密性、数据完整性、抗抵赖性** |
